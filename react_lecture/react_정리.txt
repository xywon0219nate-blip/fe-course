1. React의 탄생
    (1). 탄생 배경
    - React는 페이스북의 개발팀이 화면 업데이트를 위해 개발하던 중 탄생.
    - React는 자바스크립트(JavaScript)기반의 라이브어리. (언어X)
    - 2013년도 등장한 선언형 방식으로 UI를 표현
    - 현재는 2024(React. 19v)버전을 API 지원 : 항상 최신 버전으로 개발 권장.

    (2). 새로운 기술이 필요한 이유
    - 기존의 기술 한계점 발생. (정적인 웹 구축에 초점, 대규모 앱 구축에 부적)
    - 페이스북의 요청 : 
      다양한 인터렉션(사용자와의 양방향 소통)
      변화가 잦은 대규모 앱 필요
    
    ❗️핵심 목적
    - 변화가 자주 일오나는 대규모 애플리케이션에 적합한 쉽고 효율적인 라이브러리 개발.

2. React의 특징
    (1). 컴포넌트 기반
        - UI를 독립적이고 재사용 가능한 컴포넌트 단위로 분리
    (2). 가상 돔(Vitual DOM)
        - 실제 DOM을 복제하여 가상돔에서 필요한 부분만 업데이트를 진행한 후, 한번에 실제 DOM에 반영하여 빠른 업데이트를 진행.
    (3). 단방향 데이터 흐름
        - 부모 컴포넌트 -> 자식 컴포넌트로 데이터를 전달함 (단방향이기에 반대의 경우는 불가능.)
